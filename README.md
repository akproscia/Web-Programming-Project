# Web-Programming-Project
Anna and Michely's project for CSC 324 - Web Programming.

## Our Goal
We want to create a social media platform focused on sharing and discovering entertainment with your friends. Users will be able to create personalized profiles where they can share their favorite movies, songs, games, and other media. 

We were inspired by applications like Letterboxd and Airbuds, both of which focus on sharing and viewing your friend’s current interests. While our platform is inspired by those applications, it differs by allowing users to recommend not only just movies or music but also other types of media, all in one place.

## Structure / How To Run
We created html and/or js files for the login, register, profile, new post, settings, and home page. Open the live server using the login page or the register page. Use "Demo" as the display name and username, "1234" as the password. From there, you should be brought to your profile page.
